# pyalimony

[![License](https://img.shields.io/github/license/jtprogru/pyalimony)](./LICENSE)
[![uv](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/astral-sh/uv/main/assets/badge/v0.json)](https://github.com/astral-sh/uv)
[![Ruff](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/astral-sh/ruff/main/assets/badge/v2.json)](https://github.com/astral-sh/ruff)

Консольная утилита: считает ежемесячный платёж по алиментам, платёж в счёт задолженности и срок её погашения по нескольким исполнительным производствам сразу.

Расчёт учитывает прекращение алиментов при совершеннолетии (ст. 120 СК РФ), предел удержания из дохода (ст. 99 ФЗ-229) и доли по ст. 81 СК РФ. Правовые основания с ссылками на источники — в [docs/LEGAL.md](./docs/LEGAL.md).

Расчёт справочный. Юридически значимая величина задолженности — та, что указана в постановлении судебного пристава-исполнителя.

## Установка

Нужен [uv](https://docs.astral.sh/uv/) и Python 3.14+.

```bash
git clone https://github.com/jtprogru/pyalimony.git
cd pyalimony
uv sync
```

## Конфигурация

Входные данные читаются из `~/.config/alimony.yaml`. За образец можно взять `config.yaml` из репозитория:

```bash
mkdir -p ~/.config && cp config.yaml ~/.config/alimony.yaml
```

```yaml
---
net_income: 100000              # чистый доход в месяц после НДФЛ
other_withholding_percent: 0.0  # удержания по неалиментным ИП, % (необязательно)

children:
  - surname: 'Иванов'
    name: 'Иван'
    patronymic: 'Иванович'      # необязательно
    birthday: '30.11.2006'      # ДД.ММ.ГГГГ или ГГГГ-ММ-ДД
    alimony:
      total_percent: 40.0       # весь удерживаемый процент по этому ИП
      alimony_percent: 25.0     # из них текущий платёж (ст. 81 СК РФ)
      debt: 200000              # задолженность (необязательно, по умолчанию 0)
      debt_as_of: '01.03.2026'  # дата постановления пристава, обязательна при debt > 0
```

Разница `total_percent - alimony_percent` уходит в погашение задолженности. После совершеннолетия ребёнка текущий платёж прекращается, и весь `total_percent` идёт на долг.

Вместо `alimony_percent` можно указать `alimony_fixed` — алименты в твёрдой денежной сумме (ст. 83 СК РФ). Индексацию по прожиточному минимуму (ст. 117 СК РФ) программа не делает, сумму нужно обновлять вручную.

Ещё три необязательных поля описывают нестандартные ситуации:

```yaml
    obligation_ended: '01.03.2026'  # обязательство прекратилось раньше 18 лет
    disabled: true                  # нетрудоспособный ребёнок, ст. 85 СК РФ
    alimony:
      closed: true                  # производство прекращено, в расчёт не входит
```

`obligation_ended` — фактическая дата прекращения обязательства при эмансипации (ст. 27 ГК РФ), браке до совершеннолетия (п. 2 ст. 21 ГК РФ) или усыновлении ребёнка другим лицом. С этой даты текущий платёж обнуляется, а всё удержание идёт на долг.

`disabled` снимает прекращение по возрасту: перед нетрудоспособным ребёнком обязанность бессрочна. Такие алименты взыскиваются в твёрдой сумме, поэтому используйте `alimony_fixed`.

`closed: true` помечает прекращённое производство. Остальные поля тогда не нужны, а любые ненулевые проценты и долг при этом флаге считаются ошибкой конфига.

`net_income` — это доход после НДФЛ и не только оклад: премии, отпускные, больничные, доходы от аренды и самозанятости тоже входят в базу удержания по [перечню ПП РФ № 1908](https://www.consultant.ru/document/cons_doc_LAW_399920/).

## Запуск

```bash
uv run pyalimony                             # отчёт на сегодня
uv run pyalimony --as-of 01.01.2027          # прогноз на дату
uv run pyalimony --config ./alimony.yaml     # другой конфиг
uv run pyalimony --json                      # машинный вывод
```

Отчёт печатает по каждому ИП текущий платёж, платёж в счёт долга, остаток задолженности на расчётную дату и прогноз погашения, а в конце — замечания о расхождениях с нормами: превышение предела удержания, отклонение от долей ст. 81, устаревший снимок задолженности, производство, которое пора прекращать.

## Разработка

```bash
make install   # venv с dev-зависимостями + конфиг в ~/.config
make check     # линт, форматирование, типы и тесты — то же, что гоняет CI
make help      # список всех целей
```

Без `make` то же самое напрямую:

```bash
uv sync --all-groups     # окружение вместе с dev-зависимостями
uv run ruff check .      # линт
uv run ruff format .     # форматирование
uv run mypy pyalimony/   # типы
uv run pytest --cov      # тесты, порог покрытия 85 %
```
